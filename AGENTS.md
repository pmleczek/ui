# AGENTS.md

Guidance for coding agents working in this repository.

## Overview

Zero-dependency React component library.

## Commands

- `pnpm install` - install workspace dependencies
- `pnpm format` - runs `oxfmt` formatting check
- `pnpm format:fix` - runs `oxfmt` formatting
- `pnpm lint` - runs `oxlint` linting check
- `pnpm lint:fix` - runs `oxlint` linting and applies safe fixes
- `pnpm typecheck` - runs TypeScript type check
